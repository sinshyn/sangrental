# SangRental frontend

Next.js App Router + TypeScript + Tailwind CSS 4. Xem README.md và docs/DEPLOYMENT.md tại repository root.

`npm ci`, `npm run typecheck`, `npm run build`, `npm run dev`.

`components.json`, CSS variables, alias và `src/components/ui` chuẩn bị cho shadcn/ui. Button hiện tại là component nội bộ, chưa được sinh bởi shadcn CLI.
